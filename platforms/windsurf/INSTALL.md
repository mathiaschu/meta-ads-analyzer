# Windsurf — Install Guide

## Quick Install

```bash
# From the meta-ads-analyzer repo root
cp platforms/windsurf/.windsurfrules .windsurfrules
```

Or use the universal installer:

```bash
bash scripts/install.sh windsurf
```

## Usage

Windsurf Cascade will automatically follow the Meta Ads rules when analyzing campaign data.

## MCP Setup (Optional)

Windsurf supports MCP via settings. Configure the `meta-ads-mcp` server with your credentials.

Run `bash scripts/setup.sh` first.
